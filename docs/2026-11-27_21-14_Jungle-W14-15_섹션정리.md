- 핵심 사이클: Forward(예측·캐시 저장) → Loss(틀린 정도 숫자 하나) → Backward(chain rule로 gradient) → Update(`W -= lr*dW`, 제자리).

## 02. 2. 신경망이란
- 한 줄 요약: 신경망 개념 + 코드 구조 전체 + forward/Affine/ReLU/배치/은닉층 기초.
### 배운 것 / 핵심 개념
- 신경망 = 곱하고 더함 → 꺾음 → 또 곱하고 더함 → 점수. 틀리면 조금씩 고침 반복.
- 흐름: `x(N,784) → Affine → ReLU → Affine → logits(N,10) → Softmax+CE → loss`.
- 파일별 역할: `data.py`(load_mnist, 0~1 정규화) / `layers.py`(Affine ✓, BN·Dropout 옵션) / `activations.py`(ReLU ✓) / `losses.py`(SoftmaxWithLoss ✓) / `network.py`(TwoLayerNet 조립, 읽기만) / `optimizers.py`(SGD ✓, Adam 제공) / `training.py`(train TODO 1~4, gradient_check·evaluate·plot 제공).
- 꼭 알 포인트:
  1. **params 공유**: `Affine(self.params["W1"], ...)` 배열 그대로 넘김 → optimizer가 `-=`로 제자리 수정해야 레이어도 바뀜. `params[k] = 새배열`이면 연결 끊김 (SGD 함정).
  2. forward 결과 = logits. 예측은 logits에 argmax (softmax는 순서 안 바꿈).
  3. backward = `reversed(layers)`, dx를 앞으로 넘김 = chain rule.
  4. 레이어는 forward 때 값 기억 (Affine x, ReLU mask) → forward 먼저.
  5. `gradient_check` = ±eps 흔들어 수치 미분 vs backward 비교.
- **gradient shape = 파라미터 shape** 항상 같음 (db1 = (128,)).
- forward 공통 패턴: ① backward용 저장 → ② 계산 → ③ return. Loss는 layers 리스트 밖에서 따로: `loss = criterion.forward(model.forward(x), y)`.
- 세 forward 비교:

| | Affine | ReLU | SoftmaxWithLoss |
|---|---|---|---|
| 하는 일 | 섞음 | 꺾음 | 채점 |
| 수식 | `xW+b` | `max(0,x)` | `-mean(log softmax(z)[정답])` |
| 출력 | (N,H) | 같은 shape | 스칼라 |
| 파라미터 | W,b | 없음 | 없음 |
| 저장 | x | mask(x≤0) | y_prob, y_true |
| 함정 | b 브로드캐스트 | mask 방향 | exp overflow→`z-max`, log(0), 라벨 형식 |

- 헷갈렸던 점(답변 내 정정): `y_true` = 정수 라벨 `(N,)`, 원핫 아님. log(0) 방지는 eps 더하기 X → `np.clip(p, 1e-7, 1)` (과제 코드 기준; 더하면 grad check 실패할 수 있다고 안내).
- 검증: logits 전부 0이면 loss = ln10 ≈ 2.3026.
- W·b·N·D·H 결정: 데이터가 정함(D=784, 출력 10) / 사람이 정함(N 배치, H 은닉 — 하이퍼파라미터) / 학습이 정함(W 작은 랜덤 시작, b 0 시작).
- 배치 = 한 번 고칠 때 보는 사진 묶음 (1장은 흔들림, 전체는 느림 → 미니배치). 비유: 학생 100명 평균 보고 수업 고침.
- 은닉층 = 중간 특징 칸. 크면 표현력↑·과적합 위험, 작으면 부족.
- ReLU 필요 이유: `(x·W1)·W2 = x·(W1·W2)` → 합쳐짐. ReLU = 스위치.
- Affine 목적: 출력 칸 하나 = Σ(픽셀×w) + b, "가중 합계 투표". W 열 하나 = 출력 칸 하나의 가중치 세트.

## 03. 3. 밑바닥부터 시작하는 딥러닝 책

### 배운 것 / 핵심 개념
- 책: 사이토 고키, Python+NumPy만으로 구현. 1권 장: 1 파이썬 / 2 퍼셉트론 / 3 신경망 / 4 학습 / 5 오차역전파 / 6 학습 기술 / 7 CNN / 8 딥러닝 / 부록 Softmax-with-Loss 그래프. 후속: 2권 NLP, 3권 DeZero, 4권 강화학습, 5권 생성모델.
- 퍼셉트론: `w1x1 + w2x2 + b > 0 ? 1 : 0`. AND(0.5,0.5,-0.7), NAND(-0.5,-0.5,0.7), OR(0.5,0.5,-0.2). XOR은 직선 하나로 불가 → `XOR = AND(NAND, OR)` 다층.
  - 퍼셉트론 vs 신경망: 계단 함수·사람이 가중치 정함 vs 매끄러운 함수·데이터로 학습.
- 매끄러운 함수 = 점프 없고 의미 있는 기울기. 계단 함수는 기울기 0 → 학습 불가.
- 시그모이드 `1/(1+e^-x)`: 0~1 S자, `h' = h(1-h)`, 최대 0.25 → 깊으면 기울기 소실.
- ReLU `max(0,x)`: 빠름, 양수 기울기 1 → 소실 적음. x=0에서 꺾여 엄밀히는 매끄럽지 않지만 학습엔 문제 없음. 단점: 죽은 ReLU → Leaky ReLU.
- 학습/결정: "스스로" = 사람이 W를 직접 안 정함. 결정 = argmax. 학습 = 손실→역전파→`W -= lr·grad` 반복. 비유: 눈 가리고 산 내려가기(높이=손실, 경사=기울기, 보폭=학습률). 한계: 편향 학습, 오버피팅, 극솟값, 하이퍼파라미터는 사람이.
- 가중치: 입력에 **곱해짐**(더해지는 건 편향). 비유: 외출 결정(날씨+3, 친구+1, 숙제−5, 편향−0.5). 가중치 = 판단 기준/성격, MNIST에선 "7 모양 템플릿". 신경망의 지식은 전부 가중치에.
- 은닉층: 입출력 사이 층. hidden = 사람이 안 정함. 특징 단계적 추출, 문제를 풀기 쉬운 형태로 변환(XOR의 s1,s2). 활성화 없으면 은닉층 무의미. 깊게 = 딥러닝.
- 활성화 함수: 가중합 `a` → `h(a)`. 역할 = 비선형성. 조건: 비선형, 기울기 있음, 빠름. 표: 계단/시그모이드/ReLU/소프트맥스(분류 출력)/항등(회귀 출력).
- dW = ∂L/∂W, db = ∂L/∂b. `dW = xᵀ·dout` (784,4)@(4,128)→(784,128). `db = dout.sum(axis=0)` (b가 브로드캐스팅으로 모든 샘플에 더해졌으니 합). `dx = dout·Wᵀ` → 앞 층 전달.
- 헷갈렸던 점: 내 이해 "가중치를 입력에 더한다" → 실제: 곱함, 더하는 건 편향.

### 배운 것 / 핵심 개념
- 공부 순서: README Day1→2→3. 사전 자료 3Blue1Brown 1~4편, 밑바닥 3~5장. `TwoLayerNet` 먼저 읽기. Day2 순서는 Softmax→ReLU→Affine(출력부터 거꾸로). 요령: 2×3 손계산 → 해당 테스트만(`pytest tests/test_affine.py -v`, `python tools/selfcheck.py --day 1`) → LEARNING_LOG 기록.
- 층 쌓기 vs 학습 반복: 층 = 구조(설계 시 결정, 층마다 자기 W,b). 학습 반복 = 같은 구조에서 W,b 숫자만 고침. 1 iteration = 미니배치 1회, 1 epoch = 전체 1바퀴. 비유: 공정 단계 수 vs 기계 세팅 조정.
  - 헷갈렸던 점: 내 이해 "층 쌓기 = 학습 계속 돌리기" → 실제: 다른 개념. 층 통과는 한 번의 예측 안에서 일어남.
- 행렬곱: `C[i][j]` = A i행 · B j열 내적. `[[1,2,3],[4,5,6]] @ [[1,0],[0,1],[1,1]] = [[4,5],[10,11]]`. `(m,n)@(n,k)=(m,k)`, 안쪽 n 사라짐. 틀리면 `shapes not aligned`. `@` 행렬곱 vs `*` 원소곱.
- `(2,3)·(3,2)→(2,2)` 표기 = shape만 적은 것. `·` 행렬곱, `→` 결과.
- 순전파: 층마다 가중합 + 활성화. 3.4절 3층: (2,)→W1(2,3)→sigmoid→W2(3,2)→sigmoid→W3(2,2)→항등. 순전파 vs 역전파 표.
- 배치 처리: W shape 그대로, 앞 차원만 100. `np.argmax(y, axis=1)` = 행마다 최대 인덱스, axis로 지정한 차원 사라짐. `np.sum(p == t)` True=1. 빠른 이유 = Python 루프 감소 + BLAS. 학습에선 미니배치 평균 → backward `/ batch_size`.
  - 헷갈렸던 점: "100장씩 한 번에 본다"가 이해 안 됨 → 실제: 이미지를 행으로 쌓은 표에 W를 한 번 곱함. 행끼리 안 섞여서 1장씩 계산과 결과 동일. 동시에 "보는" 게 아니라 명령을 100번 → 1번. 비유: 시험지 묶음 채점기.
- 손실 함수 = 틀린 정도를 숫자 하나로 재는 자 (다트 비유). 숫자 하나여야 "이 방향으로 바꾸니 2.3→2.1" 판단 가능.
- MSE `1/2·Σ(y−t)²`: 모든 칸, 제곱(부호 제거·큰 오차 벌), 1/2은 미분 정리용. 최대 약 1에서 멈춤 → 회귀용.
- CEE `−Σ t·log y`: 원핫이라 정답 칸만 남음 → `−log(y정답)`. 확신하고 틀리면 무한대로 벌 → 분류용, 학습 신호 강함. 비교: p=0.9 → MSE 0.01/CEE 0.11, p=0.001 → 0.75/6.91.
- 초기 loss: 모든 클래스 ≈0.1 → `−log 0.1 = ln10 ≈ 2.303`.
- 정확도 대신 손실 쓰는 이유: 정확도는 계단(0%→0%→100% 점프), 손실은 비탈길(1.20→1.17 바로 반응). 연속 = 끊김 없음, 매끄러움 = 꺾임도 없어 어디서든 기울기.
  - 헷갈렸던 점: 내 이해 "조금만 바꿔도 잘 바뀐다" → 실제: "조금 바꾸면 조금 바뀐다". 연속과 매끄러움은 엄밀히 다름.
- 미분 = x 아주 조금 바꿨을 때 y 변화 비율 = 기울기. 수치 미분 `(f(x+h)−f(x−h))/2h` (x²@3 → 6). 해석적 미분 x²→2x. 미분값 반대 방향으로 W 이동 = 경사하강법.
- 역전파 = Backward. 손실이 끝에 있어서 뒤에서부터 "네 탓 이만큼" 전달. 릴레이 비유.
- 역전파가 빠른 이유: 공통 구간 기울기를 한 번만 구하고 모든 W가 공유. 수치 미분은 파라미터 ≈39,760개 × 순전파 2번 ≈ 8만 번 vs 역전파 ≈ 순전파 2~3번. 택배 대전 허브 비유.
- 순전파 캐싱: 순전파가 캐시(x, mask)를 만들고 역전파가 씀. 다음 반복 재사용 불가(배치·W가 바뀜). 추론에선 KV 캐시처럼 재사용.
- 연쇄 법칙 = 단계별 변화율 곱. 톱니 3×2=6. `z=(3x)²` x=1 → 3×6=18 = `18x`. 각 층은 `dout × 자기 국소 미분`. ReLU 국소 미분 1 or 0.
- 원-핫: 정답 위치만 1. 이유: 출력 shape 맞춤, 숫자 크기에 잘못된 순서 의미 방지. `확률 − 원핫` → 정답 칸 음수(올려라), 오답 칸 양수(내려라). 과제는 정수 인덱스 라벨.
- `np.max(a)`: 최댓값. softmax overflow 방지 `a − max`. 배치면 `np.max(a, axis=1, keepdims=True)` → `(B,1)`.

## 05. 5. 밑바닥딥러닝 grill
- 한 줄 요약: 3~5장 요약 파일로 grill(문제 풀이) — README 과제 기준 Round 1(Q1~Q6), 사이드 채팅에서 답·채점·개념 보충.
### 배운 것 / 핵심 개념
- 책 vs 과제 차이: 활성화 Sigmoid→ReLU / 정답 원핫→정수 라벨 / softmax max 전체→행마다 / log(0) `+1e-7`→`np.clip` / SGD 제자리 필수.
- Round 1 문제(과제판): Q1 Affine shape·브로드캐스팅 / Q2 `self.x` 저장 이유 / Q3 Affine 두 층 = 한 층 증명 / Q4 ReLU mask (a)(b)(c) / Q5 logits·max-shift 증명·행별 max / Q6 추론 시 softmax 생략 이유.
- A1: hidden size = 은닉 뉴런 수, 기본 128. `x(100,784)`, `W1(784,128)`, `b1(128,)`, `x@W1 (100,128)`, `+b1 (100,128)`. b1은 `(1,128)`로 보고 axis 0 방향 브로드캐스팅 → 나중 `db = sum(dout, axis=0)` 이유. `W2(128,10)`, `b2(10,)`, logits `(100,10)`.
  - 헷갈렸던 점: 내 답 `W1 = (784,100)` → 실제 `(784,128)`. 100은 배치라 W에 안 들어감.
- A2: `self.x` 저장 → **dW 계산용** (`dW = xᵀ@dout`). dx는 dout·W, db는 dout만 필요. backward 때 x 다시 못 받음.
  - 내 답 "원본이?" / "backward" → 반쯤 정답. "어떤 계산"까지 말해야 함.
  - 전치: `.T` 행↔열, `A[i,j]==A.T[j,i]`. Q2-1: `x.T @ dout` (784,100)@(100,128)→(784,128).
  - 헷갈렸던 점: 내 답 `x.T * dout` → `*`는 원소곱이라 에러, `@` 써야 함. `*`는 같은 shape 원소별일 때(MulLayer, mask).
  - 꼬리 Q2-2(dx, db) 미답.
- A3: `(x·W1 + b1)·W2 + b2 = x·(W1·W2) + (b1·W2 + b2)` → Affine 한 층. 선형 분류기와 같아짐.
  - 헷갈렸던 점: 내 답 `b1·W1 + b2` → 실제 `b1·W2 + b2`. shape 검산: `b1(128,)·W1(784,128)` 불가.
  - 다른 사이드 답 "h(h(x)) = xW+b" → 방향 맞지만 전개 빠짐(6/10). 꼬리 Q3-1(ReLU(a+b) ≠ ReLU(a)+ReLU(b)), Q3-2(ReLU 왜 비선형) 미답.
- mask = 원래 배열과 같은 shape의 True/False 배열, 위치만 기억. `a[m]` 고르기, `a[m] = -1` 고른 칸 바꾸기.
- self = 객체 자신. `self.xxx`는 메서드 간 값 전달 통로, 지역 변수는 사라짐.
- A4 정답: (a) mask `[[T,T,F],[F,T,F]]`, 출력 `[[0,0,2],[3,0,0.5]]`. (b) forward 결과 동일(0은 0), 차이는 backward: `<=`면 x=0 칸 gradient 0, `<`면 통과. 과제 테스트는 `<=` 기준. (c) x는 호출한 쪽과 공유 배열 → 원본 수정 시 테스트 실패, gradient check 반복 forward 틀어짐, 디버깅 불가 → `x.copy()`.
  - SGD는 공유를 **이용**(in-place), ReLU는 공유 피해를 **막음**(copy). 같은 성질 반대 방향.
- mask가 필요한 이유: forward는 `np.maximum(0,x)`로 충분. backward가 받는 건 dout뿐이라 x가 어디서 ≤0이었는지 모름 → forward에서 기록. `self.x` 저장 후 재계산도 가능하나 mask가 의도 명확 + 같은 기준 보장.
- backward 역할: "이 층 입력/가중치 조금 바꾸면 loss 얼마나 변하나" 계산. 받는 것 `dout`, 돌려주는 것 `dx`, 가중치 층은 `dW, db` 저장.
- 역전파(알고리즘 이름) = backward(코드 메서드 이름).
- x=0 gradient: ReLU 기울기 x>0 1, x<0 0, x=0 미정의 → 관례 0. 예 `x=[-2,0,3]`, `dout=[5,5,5]` → `<=`: dx `[0,0,5]`, `<`: `[0,5,5]`. 이 차이가 `dW1`·SGD 갱신량까지 전달. 실제 학습에선 정확히 0.0 드묾, 과제 테스트엔 중요.
- logits = 마지막 Affine 날것 점수, 확률 조건(0~1, 합 1) 불만족.
- softmax `exp(a_k)/Σexp(a_i)`: 양수화 + 합 1, 순위 유지(Q6 힌트).
- axis: `np.max(a)` 전체 / `axis=0` 열마다 / `axis=1` 행마다. logits는 행 = 이미지 → axis=1.
- keepdims: 축을 길이 1로 남김. `(2,3) − (2,1)` OK, `(2,3) − (2,)` ValueError. **정사각형이면 에러 없이 틀림** (`[[1,9],[3,4]] − [9,4]` → 열 단위로 빠짐). 배치=클래스 수(10)일 때 조용히 틀림 → `keepdims=True` 습관. softmax에서 max·sum 두 번 사용.
- exp = eˣ, e ≈ 2.718. exp(0)=1, exp(1000)=inf.
- A5 채점: (a) △ 확률 조건 2개 구체적으로. (b) `exp(a−c) = exp(a)·exp(−c)` → 분자·분모 `exp(−c)` 약분 → 원래 softmax. (c) △ 직관 맞으나 원인은 수치 한계: 전체 max 1000 빼면 2행 `[-999,-998,-997]` → exp 언더플로 0 (`exp(-997)≈10⁻⁴³³` < float64 최소 ≈10⁻³⁰⁸) → 0/0 = nan. 행별 max 빼면 각 행에 exp(0)=1 보장.
  - 헷갈렸던 점: 내 이해 "전체로 빼면 다른 이미지가 결과에 영향" → 실제: 수학적으론 같음, 문제는 언더플로→nan.

## 09. 질문
- 한 줄 요약: 브로드캐스팅 규칙, forward·backward 전체 수식, softmax, exp, dZ2.
### 배운 것 / 핵심 개념
- 가운데 같아야 하는 규칙은 `@`(행렬곱)에만. `(B,H) + (1,H)`는 덧셈 = 브로드캐스팅.
- 기호: B 배치, D 입력 차원 784, H 은닉 128.
- 브로드캐스팅 규칙: ① 축 모자라면 왼쪽에 1 ② 같거나 한쪽 1이면 OK, 1인 쪽이 늘어남 ③ 어긋나면 ValueError. 메모리 복사 X.
  - 연습: `(4,3)+(3,)` ✓ / `(4,3)+(4,)` ✗ / `(4,3)+(4,1)` ✓ / `(4,1)+(1,3)` ✓ (양쪽 늘어남) / `(4,3)*5` ✓.
  - 흔한 실수 `a − a.max(axis=1)` → `(B,H)−(B,)` 에러 → keepdims.
- forward 수식:
  - `Z1 = XW1 + b1` (B,H) / `A1 = max(0,Z1)` / `Z2 = A1W2 + b2` (B,10) logits / `Y = softmax(Z2)` / `L = −(1/B)Σ log Y[i,tᵢ]`.
  - 이 세션 답변은 loss에 `+1e-7` 사용 (과제 코드는 `np.clip` — 02·05 세션 참고).
- backward 수식:
  - `dZ2 = (Y − T)/B` — 정답 칸 `y−1`, 나머지 `y`. `/B`는 평균 loss라서.
  - `dW2 = A1.T @ dZ2` (H,10), `db2 = dZ2.sum(axis=0)` (10,), `dA1 = dZ2 @ W2.T` (B,H).
  - `dZ1 = dA1 ⊙ 1[Z1>0]` (mask 칸 0).
  - `dW1 = X.T @ dZ1`, `db1 = dZ1.sum(axis=0)`. dX는 계산되지만 갱신 안 함.
  - SGD: `W ← W − η·∂L/∂W`. gradient는 loss 커지는 방향 → 빼야 줄어듦.
- 순서 이유(REPORT.md:30용): ① backward는 forward 저장값 필요 ② gradient는 loss에서 시작 ③ update는 모든 gradient 후 — `dA1 = dZ2 @ W2.T`는 갱신 전 W2 써야 함.
- 팀원 설명용 한 줄: loss가 `Y−T` 오차 신호 → Affine은 "입력.T @ 신호"로 dW, "신호 @ W.T"로 아래 전달 → ReLU는 꺼진 칸 차단 → optimizer가 `lr × grad` 뺌.
- gradient check: `(L(W+h)−L(W−h))/2h` vs backward dW.
- softmax: 점수→확률. 특징 ① 순서 유지(예측은 argmax만) ② 큰 값 강조(차이 1 → 약 2.7배, "soft max") ③ 같은 수 더하고 빼도 동일 → max 빼기. Softmax+CE 합쳐 미분 → `y − t` → SoftmaxWithLoss로 묶는 이유.
- exp: eˣ. softmax에 쓰는 이유 — 항상 양수, 큰 값 키움, 미분 = 자기 자신, log와 상쇄 → `y−t`.
- dZ2 = ∂L/∂Z2, shape (B,10). 정답 칸 음수(올리면 loss↓), 오답 칸 양수. Y=T면 0. 역전파 시작점 = "loss가 보내는 오차 신호".

## 11. 파이썬 질문
- 한 줄 요약: 참조 vs 복사, Affine x 배열, `@`, 브로드캐스팅, 전치.
### 배운 것 / 핵심 개념
- 파이썬 `=` = **참조**(이름표 하나 더). 값 복사 아님.
- 얕은 복사: `a.copy()`, `a[:]`, `list(a)`, `copy.copy(a)`, dict는 `d.copy()`. 중첩 객체는 여전히 공유. 깊은 복사 `copy.deepcopy(a)`.
- NumPy: `x.copy()` 진짜 복사. **슬라이싱 `x[:]`는 view(원본 공유)** — 리스트와 다름. `x += 1`, `x[...] = 0`은 제자리(공유 변수 모두 반영), `x = x + 1`은 새 배열.
- 불변 객체(숫자·문자열·튜플)는 복사 필요 없음.
- Affine forward의 x = NumPy 2D 배열 `(batch_size, input_dim)`. `self.x = x` 참조 저장 OK, copy 불필요(중간에 제자리 수정 없음, 다음 층이 새 배열 만듦). 호출 측이 backward 전 x를 in-place 수정할 때만 문제.
- 당시 [layers.py:52](../src/layers.py) `self.x = ;` 문법 에러 지적 (`;` 불필요).
- `@` = 행렬곱 연산자(Python 3.5+), `np.matmul`. `[[1,2],[3,4]] @ [[5,6],[7,8]] = [[19,22],[43,50]]`.
- 브로드캐스팅은 따로 하는 작업 아님 → `x @ W + b` 그냥 `+`. 규칙: 오른쪽 끝부터, 같음/1/없음. `(4,128)+(4,)` ❌. backward는 `db = dout.sum(axis=0)` (BatchNorm `self.dbeta = dout.sum(axis=0)` layers.py:118과 같은 원리).
- 전치 `x.T`. backward에서 `self.dW = self.x.T @ dout` → (784,4)@(4,128) = (784,128).
